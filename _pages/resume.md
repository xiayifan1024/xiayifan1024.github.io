## 关于我

我是夏一帆，目前在哈尔滨工业大学（深圳）攻读电子信息专业博士学位，导师为张淼教授。此前，我在中国科学院计算技术研究所智能信息处理重点实验室担任工程师，主要从事视觉识别算法研发、模型优化与工程化部署。我在中国科学院大学获得电子信息专业硕士学位，研究方向为合成孔径雷达（SAR）图像目标检测；在中国矿业大学（北京）获得遥感科学与技术工学学士学位，辅修计算机科学与技术。

目前，我关注**多模态模型的高效视频理解、模型压缩与端侧推理优化**，尤其是如何结合视频的时空变化与语言语义，在有限计算和内存预算下保留关键视觉信息。

## 研究兴趣

- **高效视频理解与视觉 Token 压缩**：探索利用轻量卷积网络和时空变化信息，在视觉编码前进行 Token 选择，减少视频冗余并降低多模态推理开销。
- **语言引导的时空信息选择**：结合问题语义、图文对齐与局部视觉特征，探索与对象、动作和时间关系相关的视觉证据选择方法。
- **模型压缩与推理加速**：关注知识蒸馏、剪枝、量化及其与模型结构和推理流程的协同优化，兼顾模型精度、延迟与内存占用。
- **边缘智能与算法系统协同优化**：关注多模态模型和小型语言模型在资源受限设备上的部署，以及面向端侧 Agent 的上下文管理、缓存复用与推理调度。
